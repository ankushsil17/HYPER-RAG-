# HYPER-RAG-
This repository contains the code, configurations, and results for HYPER-RAG: Evaluating Hyperparameter Trade-offs in Biomedical Retrieval-Augmented Generation. The study explores how retriever type (dense, BM25, hybrid), reranking, and top-k settings affect biomedical question answering performance on the COVID-QA dataset. We evaluate with lexical (F1/EM), semantic similarity, groundedness, and efficiency (latency) metrics. The repo includes per-query and aggregated results in CSV form, generation prompts, and modular code for reproducing experiments on Kaggle or local GPU setups.
